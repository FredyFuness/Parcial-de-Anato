# Repaso interactivo de Anatomía II

Cuestionario web para practicar contenidos de anatomía, histología y embriología mediante preguntas de opción múltiple. Transforma material de estudio en sesiones con retroalimentación y revisión de resultados.

## Funciones
- Selección de temas.
- Modo estudio con explicación inmediata y modo examen con resultados al finalizar.
- Orden aleatorio o agrupado por tema.
- Seguimiento del progreso y los aciertos.
- Resultado global y desglose por tema.
- Revisión de respuestas y práctica de preguntas falladas.

## Tecnologías y estructura
HTML, CSS y JavaScript en un único archivo: `Examen_Anatomia.html`. El banco de preguntas está incluido en el código; no necesita backend ni base de datos.

## Ejecutar
Desde la raíz:
```bash
python -m http.server 8000
```
Abre `http://localhost:8000/Examen_Anatomia.html`. Selecciona temas y modo antes de comenzar.

## Alcance
Herramienta de repaso académico. El contenido debe contrastarse con los apuntes y fuentes de la asignatura. Los resultados representan una sesión de práctica, no una evaluación oficial.
